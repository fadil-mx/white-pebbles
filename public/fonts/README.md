# Fonts folder (currently empty — no action needed)

The current design uses **Fraunces** loaded automatically from Google Fonts.
Nothing to download or install here.

This folder exists in case you want to switch to a paid font later (like Recoleta from Latinotype). If you do:

1. Buy and download the font from the foundry
2. Place `.woff2` files here
3. Update `src/app/layout.tsx` to import them via `localFont`

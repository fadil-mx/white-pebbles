# Optional: Place .glb 3D models here

The current design uses procedural macarons (built with Three.js geometry) — no model file needed.

If you want to upgrade to a real GLB model later:
1. Download a macaron .glb from https://sketchfab.com/3d-models/macaron-0516d68b862b490ea63be880df0c4c21
2. Place it here as `macaron.glb`
3. Follow the GLB swap instructions in the main README.md
